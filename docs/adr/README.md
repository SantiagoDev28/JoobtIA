# Architecture Decision Records (ADRs)

ADRs document **why** a technical decision was made.  
Language: **English** (product docs/UI remain Spanish).

## Status values

- `proposed` — under discussion  
- `accepted` — decision locked for now  
- `deprecated` — superseded  
- `rejected` — considered and declined  

## Naming

`NNNN-short-title.md` — zero-padded sequence, e.g. `0001-job-sourcing-strategy.md`

## Template

Copy `_template.md` when opening a new ADR.
